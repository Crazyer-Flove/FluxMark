# 功能回归清单

使用内置全景指南和一份临时 Markdown，避免覆盖日常文档。分别在 Chromium 网页版和 Windows 便携版执行适用场景。

| 范围 | 检查步骤与预期结果 |
| --- | --- |
| 启动与编辑 | 新建、打开、修改 Markdown。插入标题、列表、表格、任务清单、代码和公式。检查撤销与重做，再重启确认草稿可恢复。 |
| 文件与知识组织 | 选择临时文件夹，打开同名文件并按路径筛选。添加双链，检查反向链接、星图和点击跳转。 |
| 外观 | 切换四个应用主题及正文皮肤。检查窄窗口、长文件名、对话框按钮、键盘焦点和文字对比。 |
| 放映 | 用分隔线创建标题页、长正文页和含表格的页。比较前进、返回和自适应模式，确认画面不会延迟跳动。测试批注、清屏、激光笔与倒计时。 |
| 触控 | 用实体触控屏在浏览模式放大、缩小、拖动并翻页，检查比例重置和批注模式切换。 |
| 导出 | 分别导出 Markdown、PDF、PNG、Word 和 HTML 并重新打开。检查 PDF 页码、长图边界和页眉开关。 |
| 媒体 | 从临时目录导入图片和视频。验证裁剪、播放、重新打开及导出中的呈现。 |
| AI | 使用测试文本和自己的测试凭据验证成功请求及网络错误提示。 |
| Windows 便携版 | 双击 exe 启动，从窗口菜单创建桌面快捷方式，关闭应用后通过快捷方式重新打开。 |

自动检查使用 `npm run lint` 和 `npm run build`。Windows 包使用 `npm run package:win`。
